From the hardware's side, an inference run is a traffic pattern. I work on reading that
pattern off real workloads, and on what follows from it: memory systems, on-chip and
chip-to-chip networks, and the RTL underneath.

**Focus** — operator-level traffic extraction from real inference runs · HBM bandwidth and
latency under AI access patterns · NoC topology, flow control, collective traffic · network
datapath RTL. Mostly around Chakra, ASTRA-sim, Ramulator2, gem5, vLLM and SGLang.

**Writing** — [hard-won.github.io](https://hard-won.github.io): digital design, ASIC
synthesis, PCIe, GPU architecture.
